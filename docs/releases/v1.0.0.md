# Canopy Drift 1.0.0

First stable release of the animated forest screensaver.

## Included

- Animated canopy branches and falling leaves, rendered locally with Android Canvas.
- Maple, oak, or birch tree forms and spring, summer, autumn, or winter color palettes.
- Five leaf-density choices, four wind strengths, three wind directions, three scene settings, and day, dusk, or night lighting.
- Per-setting Random, randomize-all, and optional scene rotation.
- DreamService, remote-friendly settings and preview, and a documented local settings-provider contract.
- Guided standalone install, update, and uninstall commands with release checksum verification.
- No ads, analytics, tracking, telemetry, crash reporting, or runtime network access.

## Upgrade

Install or update with `python3 install.py --serial TV_IP:5555`. Existing device settings and the selected system screensaver are not changed. For manual installation, download the APK and checksum from this release and verify with:

```bash
shasum -a 256 -c canopy-drift.apk.sha256
```

This is the initial release. There are no migration steps.
